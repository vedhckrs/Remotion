# Automation: the daily content employee

Goal: every day, without anyone at the keyboard, the Mac writes, voices, builds, renders (4K60, within the 50 percent budget), thumbnails, packages and schedules **2 Shorts and 1 long video**, uploaded to YouTube, Instagram and Facebook at fixed slots the next day. Claude Code writes the scripts; Remotion makes the pictures; nothing is generated by a video model.

## 1. Moving parts

| Piece | File | Job |
|---|---|---|
| Queue | `automation/queue.json` | Config (timezone, slots, platforms, style rotation, voice, music, budget, writer) and every planned item with its status, steps and per-platform publish state |
| Backlog | `automation/topics.md` | One topic per line, `[short]` or `[long]` prefixed. Claude Code (or you) keeps it stocked from a content calendar, comments, trends |
| Writer prompt | `automation/writer-prompt.md` | The instruction given to Claude Code headless (`claude -p`) per item; placeholders `{{topic}}`, `{{kind}}`, `{{videoId}}`, `{{style}}`, `{{targetSeconds}}`, `{{voicePreset}}`, `{{handle}}`, `{{skillDir}}` |
| Runner | `scripts/autopilot.mjs` | `plan`, `add`, `run`, `publish-due`, `status` |
| Schedulers | `scripts/install-autopilot.sh` | Two launchd agents: nightly produce, publish-due every 30 min |
| Dashboard | Autopilot panel | Same commands as buttons, queue view, per-item run |

## 2. Commands

```bash
npm run autopilot -- plan [--date 2026-09-28] [--days 3]   # queue 2 shorts + 1 long per day, topics from the backlog, styles rotated
npm run autopilot -- add --kind short --topic "..." [--when ISO] [--style tech-grid]
npm run autopilot -- run [--limit 3] [--id <id>] [--writer claude|manual] [--skip-publish] [--dry-run]
npm run autopilot -- publish-due                            # Instagram at its slot, retries (max 3 per platform)
npm run autopilot -- status
```

`run` processes items in publish order. Per item:

1. **script**: if `public/script/<id>.json` exists, use it. Else with `writer: "claude"` run `claude -p <writer prompt> --allowedTools Read,Write,Edit,Glob,Grep,Bash(node *)` (25 min timeout) and validate the result with `analyze-script.mjs --check`. With `writer: "manual"` the item waits in `needs-script` for an interactive Claude Code session (or you) to write it.
2. **icons**: `fetch-icons.mjs --from-script` for every brand or UI icon referenced.
3. **voice**: `generate-voiceover.mjs` with the queue's provider and preset (word timing comes back in the manifest).
4. **captions**: skipped when the manifest already has word timing; Whisper otherwise (`captions: "whisper"` forces it, `"off"` disables).
5. **music**: `generate-music.mjs` with the item's mood unless the script already names a track; no key = skipped, not failed. The generated track is written into the script with a credit.
6. **thumbnails**: `make-thumbnails.mjs` (16:9, cover, square).
7. **render**: `render-preset.sh Shorts shorts --4k` or `YouTube youtube-1080p --4k` with `--budget` from the queue and `--props {"videoId"}` into `out/<id>/<id>_shorts.mp4` or `_youtube.mp4`. The 9:16 master serves Shorts, Reels and Facebook Reels; the 16:9 master serves YouTube and the Facebook page video.
8. **pack**: `make-publish-pack.mjs` with the queue's handle and site.
9. **publish**: `publish.mjs --when <slot>` per platform. YouTube and Facebook schedule server-side; Instagram becomes `due` and is published by `publish-due` at the slot.

Every step is idempotent (existing outputs are skipped), so re-running an item resumes after the failed step. Logs: `automation/logs/<id>.log`. A lock file prevents overlapping runs when launchd and a dashboard click coincide.

Statuses: `needs-topic`, `planned`, `needs-script`, `producing`, `produced`, `scheduled`, `due`, `published`, `failed`, `publish-failed`.

## 3. Install the nightly job (macOS)

```bash
npm run autopilot:install -- --hour 1 --minute 30 --publish-every 30
```

- `com.remotion.autopilot.produce` runs `plan` then `run` at 01:30 under `caffeinate -i`, `Nice 10`, `ProcessType Background`, so a closed-lid Mac on power finishes three renders before morning while nothing else is affected. Budget stays whatever `queue.json` says (raise `budget` to 80 for night runs if the machine is otherwise idle).
- `com.remotion.autopilot.publish` runs `publish-due` every 30 minutes.
- Logs in `automation/logs/launchd-*.log`; `launchctl list | grep remotion`; test with `launchctl kickstart -k gui/$(id -u)/com.remotion.autopilot.produce`; remove with `--uninstall`.
- launchd only fires while the Mac is awake. Schedule a wake in System Settings > Energy (or `sudo pmset repeat wakeorpoweron MTWRFSU 01:25:00`) and keep it on power. Missed runs fire at the next wake.
- Linux: the installer prints the two cron lines instead.

Headless Claude Code needs to be logged in on that user account (`claude` once in a terminal) and the `claude` binary on the PATH the plist bakes in. A known issue: `claude -p` occasionally hangs under launchd when it cannot find a TTY; the runner applies a 25 minute timeout and the item is retried on the next run. If it keeps happening, set `writer: "manual"` and write the day's three scripts in an interactive session each morning (`autopilot status` lists the `needs-script` items).

## 4. Consistency across videos

- One style preset per channel (`styleRotation` with a single id), or rotate 2 to 4 presets by format (Shorts hype, long-form corporate). The preset fixes fonts, palette, caption style, grade, background systems and the thumbnail treatment, so thirty videos look like one channel.
- Keep the logo, handle, CTA and voice in `queue.json`; the writer prompt injects them.
- Long-form gets `targetSeconds.long` (default 420 s = 7 minutes; 14 to 30 scenes), Shorts 45 s.

## 5. Human checkpoints (recommended for the first weeks)

- Run with `--skip-publish` and review `out/<id>/` in the dashboard; then `publish.mjs` manually. Once the output is trusted, drop the flag.
- Keep YouTube uploads `private` + scheduled (default): you can still edit the title or thumbnail in Studio before the slot.
- Watch `automation/logs/` for `FAILED` lines; the dashboard shows the failing step per item.

## 6. Scaling past 3 a day

YouTube quota (10 000 units, 1 600 per upload) allows about 5 uploads a day; request more in Cloud Console. Instagram allows 100 API publishes per day. Render time is the real limit: a 45 s Short at 2160x3840x60 takes roughly 6 to 10 minutes at 50 percent budget on the M5 Air, a 7 minute 4K60 long video 60 to 90 minutes with `--hw`. Two Airs, or a Mac mini as a render node (`references/rendering.md`), double throughput without touching the queue format.
